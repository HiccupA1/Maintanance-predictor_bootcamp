# Release Readiness Checklist

- [ ] Backend tests and API contract matrix pass.
- [ ] No open P0/P1 defects.
- [ ] PostgreSQL migrations apply cleanly.
- [ ] Environment variables are documented without secrets.
- [ ] Frontend typecheck, build, tests, and audit review complete.
- [ ] Role enforcement and production authentication are approved.
- [ ] Smoke tests pass in the target environment.
- [ ] Rollback owner and procedure are confirmed.
- [ ] Demo data and script are prepared.
