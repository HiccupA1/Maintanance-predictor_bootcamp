# Product Backlog

## Epics

- **E1 Asset configuration:** equipment and criticality.
- **E2 Reading capture:** parameters, readings, history, correction.
- **E3 Alerting:** breach detection, deduplication, prioritization.
- **E4 Work management:** conversion, editing, parts, closure.
- **E5 Access and usability:** role-aware actions and accessible workflows.
- **E6 Platform quality:** API contract, testing, observability, and release readiness.
