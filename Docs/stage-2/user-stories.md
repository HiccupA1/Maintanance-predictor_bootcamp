# User Stories

- As an **Admin**, I can register equipment with a criticality from 1–5 so that assets can be prioritized.
- As a **Plant Manager**, I can configure minimum and/or maximum thresholds so that readings can be evaluated.
- As an **Operator**, I can record a reading with attribution and timestamp.
- As an **Operator**, I can correct my own reading within five minutes with a reason.
- As a **Plant Manager**, I can inspect alert context and priority rationale.
- As a **Plant Manager**, I can convert an alert into only one work order.
- As a **Maintenance Engineer**, I can record parts and close a work order with resolution notes and root cause.
- As any authorized user, I can view equipment, readings, alerts, and work orders.

## Acceptance standard

Each story requires role enforcement, validation feedback, persistence, an appropriate success state, and a test covering the primary path plus relevant boundary and denial cases.
